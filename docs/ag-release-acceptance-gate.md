## Mandatory unresolved release blockers

1. **Live schema reconciliation / provenance migration.** The read-only production audit is complete (`ag-live-schema-audit-2026-10-05.md`). It confirmed `investment_decisions.notes` is absent, `pgcrypto` lives in `extensions`, recovery tables/RPCs are not deployed, quantitative watch resolutions are compatible, and active AI uniqueness is cross-era. Draft digest calls and cross-era fencing are corrected. Migration-history drift has been reconciled without replaying the historical SQL bodies, and the BUY-authorization table has been hardened to remove direct `anon`/`authenticated` privileges. **Still blocked:** independently approve/apply the proposed provenance column and recovery migrations before actual-schema integration or activation.
2. **Durable Committee intent and payload equality.** Freeze the *full* validated Committee decision payloads at stage completion, not merely a caller-supplied ticker list. The draft canonical verifier is integrated into locked persistence completion, but full validated payload capture from actual upstream Committee output is not implemented. An isolated source-identity validator exists, but it must be invoked by the stage executor and its full original outputs and execution evidence durably frozen at checkpoint completion. Prove that every upstream decision appears exactly once in the frozen checkpoint before treating the hash comparison as authoritative. Prove that the captured batch is complete relative to the upstream Committee result; caller-supplied tickers alone cannot establish this.
3. **Durable holding-review and watchlist parity.** The draft SQL verifies frozen holding payloads and the disjoint exact union of decision kinds. Watchlist intent now has isolated frozen source identities, exact checkpoint payload binding, atomic/idempotent mutation, timeout postcondition reconciliation, and a no-blind-retry application adapter. Still wire **genuine upstream holding and watch intent capture** to immutable stage completion/orchestration and verify all of it against the audited actual schema. Passing draft tests does not establish workflow parity.
4. **Wire and exercise resumable runner.** Replace the monolithic active route with budgeted, one-stage calls. Persist stage outputs before advancing; use claim tokens, the atomic RPC and read-only reconciliation. Never automatically retry an ambiguous post-commit response. Confirm all transaction execution stays disabled.
5. **Actual-schema disposable integration.** Rebuild fixture from verified live schema and run role/RLS, retry, timeout-after-commit, cross-cycle, complete mixed-batch, watchlist, and failure-injection acceptance tests. Simplified disposable tests now reject out-of-manifest writes, missing holding rows and mismatched holding hashes; rerun these against the actual schema.
6. **Security and migration review.** Recovery tables are now drafted with no direct `anon`/`authenticated` access; authenticated recovery reads are routed through owner-scoped SECURITY DEFINER RPCs, and application decision/watch readers use those RPC boundaries. Still review every SECURITY DEFINER privilege, function search path, migration order, locking, operational recovery, rollback and observability. Independently approve any recovery migration or production deployment.
7. **Controlled reactivation authorization.** Only after blockers 1–6 pass: separately approve deployment and deliberate AG enablement, retain `executeTransactions:false`, run a controlled paper-only cycle, reconcile recorded outcomes, and retain manual stop capability.

## Stop/go rule

**STOP** if any schema assumption is unverified, the durable Committee intent or holding/watchlist coverage is incomplete, a ledger hash cannot be compared to immutable source payloads, or any stage has ambiguous writes. No amount of green mock-schema CI overrides these conditions.

**GO for review only** when branch tests are green and every open item has an owner and explicit evidence. **GO for production** requires all blockers closed and a separate explicit authorization; do not conflate a merged diagnostics branch with enabled AG.
